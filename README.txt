MITRA BALON - PETUNJUK MENJALANKAN WEBSITE

ISI FOLDER
- index.html   : struktur halaman
- style.css    : desain website
- script.js    : menu mobile dan tombol WhatsApp
- server.js    : server Node.js sederhana
- package.json : perintah npm start

CARA MENJALANKAN
1. Ekstrak ZIP ini ke folder, misalnya Desktop\WEBSITE-MITRA-BALON.
2. Buka folder tersebut di Visual Studio Code (File > Open Folder).
3. Pastikan Node.js sudah terpasang: buka Terminal > New Terminal, lalu jalankan:
   node -v
   npm -v
4. Jalankan website:
   npm start
5. Buka browser ke http://localhost:3000
6. Untuk menghentikan server, tekan Ctrl+C di terminal.

PENTING
- Semua file harus berada dalam satu folder yang sama.
- Ganti nomor WhatsApp contoh di script.js:
  const nomorWhatsApp = "6281234567890";
  Gunakan nomor bisnis Anda dalam format internasional tanpa tanda +.
- Foto ilustrasi saat ini dibuat dengan CSS; website tetap tampil tanpa perlu mengunduh foto.
- Ini adalah desain orisinal yang terinspirasi gaya situs bisnis modern, bukan salinan persis aset atau konten Balonesia.
